# Billy Tran Portfolio

A premium personal portfolio built with Next.js App Router, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm run dev
```

3. Open `http://localhost:3000`.

## Production checks

```bash
npm run lint
npm run build
```

## Customize content

Portfolio copy, links, projects, services, and stack data are centralized in:

- `data/portfolio.ts`

## Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS 4
- Framer Motion
